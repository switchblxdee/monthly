# Первый запуск во внутреннем контуре

Эта инструкция относится к прототипу. Проверяйте готовую презентацию и предупреждения аудита перед использованием. Сам файл Excel, тексты обращений и аудит не требуется передавать разработчику для запуска.

## 1. Установка

Распакуйте проект в разрешённой среде. Нужны Python 3.10+ и доступ к разрешённому источнику Python-пакетов организации. Для описанного ниже запуска с исходным шаблоном LibreOffice не нужен; он требуется для упрощённой сборки без `--template`. В каталоге проекта выполните:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

Команды активации для Windows зависят от используемой оболочки. Исходная презентация-образец в архив проекта не включена; укажите путь к ней при запуске.

## 2. Проверка на вымышленных данных

Команда создания набора требует нового имени папки и не заменяет существующую.

```bash
golos-it-create-demo --output-dir ./учебный-набор
golos-it ./учебный-набор/demo.xlsx \
  --current-sheet 'приоритет ноябрь' --previous-sheet 'приоритет октябрь' \
  --period 'ноябрь 2026' --report-month 2026-11 \
  --template '/путь/к/образцу.pptx' \
  --topic-map-json ./учебный-набор/topic-map.json \
  --statuses-json ./учебный-набор/statuses.json \
  --promises-json ./учебный-набор/promises.json \
  --output ./учебный-набор/результат.pptx
golos-it-verify ./учебный-набор/результат.pptx
```

Ожидаются 4 темы, 5 строк детализации после фильтрации и сумма 206 сигналов. Сверьте данные в `результат.audit.json` с `expected.json` и откройте презентацию. Этот запуск не обращается к GigaChat.

## 3. Проверка GigaChat

Получите у администратора внутреннего сервиса адрес модели, способ авторизации и настройки сертификатов. Укажите `GIGACHAT_BASE_URL`; при использовании `GIGACHAT_CREDENTIALS` также задайте `GIGACHAT_AUTH_URL`. Адреса модели и авторизации независимы. Наличие адресов не подтверждает, что маршрутизация проходит внутри организации.

```bash
golos-it-check-gigachat
golos-it-check-gigachat --ping
```

Первая команда не делает сетевой запрос. Вторая отправляет только фиксированное тестовое сообщение, без книги и обращений. Не публикуйте токены, ключи, адреса и другие служебные сведения при сообщении об ошибке. Если любой шаг не прошёл, параметры подключения нужно согласовать с администратором сервиса.

Если диагностика сообщает, что библиотека не подтвердила `base_url` или `auth_url`, запрос к модели не выполнялся. Проверьте версию обёртки и настройки с администратором: установленная версия должна раскрывать явно заданные адреса через соответствующие поля клиента. Это проверка параметров, а не гарантия внутренней маршрутизации. Проверить совместимость установленных Python-зависимостей можно командой `python -m pip check`; её вывод перед передачей тоже необходимо проверить на служебные сведения.

## 4. Реальный отчёт

Сначала проверьте структуру книги локально:

```bash
golos-it-inspect-workbook '/путь/к/книге.xlsx' --output ./schema-report.json
```

Отчёт содержит обезличенные номера листов, структуру и агрегированные показатели, но всё равно может подпадать под внутренние ограничения. Затем сформируйте выпуск, подставив актуальные месяц и пути:

```bash
golos-it '/путь/к/книге.xlsx' --report-month 2026-10 \
  --template '/путь/к/образцу.pptx' --output './выпуск.pptx'
golos-it-verify './выпуск.pptx'
```

Автоматический поиск листов без года сообщает предупреждение; при неоднозначных названиях задайте `--current-sheet` и при необходимости `--previous-sheet`. Формулы Excel должны иметь сохранённые вычисленные значения. Аудит содержит тексты выбранных обращений и требует тех же ограничений хранения, что и исходная книга. Сверьте темы, цитаты, числа, значки, предупреждения и вёрстку с исходными данными.

По умолчанию реальный отчёт строится локальным конвейером без GigaChat. После проверки подключения `--gigachat` включает четырёх агентов LangGraph, которые вызывают инструменты для подготовки книги, анализа, отбора содержания и сборки презентации. `--gigachat-match` дополнительно разрешает сопоставление тем и его повтор, а `--gigachat-quotes` — передачу маскированных обращений для выбора цитат и его повтор. Дополнительные режимы требуют `--gigachat`. Смотрите `agent_decisions` и предупреждения в аудите. Разрешайте эти режимы только в согласованном внутреннем окружении.

Подробности о правилах, входных файлах статусов и ограничениях — в `README.md`.
